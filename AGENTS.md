# Agent instructions

## Changelog rule
Every code/UI update to this repo MUST also be added to the developer
changelog shown in the app at Help ▸ Dev — changelog:

- File: `src/components/ChangelogModal.jsx` (`CHANGELOG` array).
- Keep it newest-first within each section, written as plain prose a
  non-developer can understand.
- Mark each entry `New`, `Improved`, or `Fixed` to match the existing tag style.
- Reuse/extend an existing `area` section when one fits; add a new section
  only when the topic is genuinely new.
